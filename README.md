## 🎮 Steam Market Opportunity Analysis

Python | Steam APIs | Excel | Power Query

End-to-end market analysis project evaluating Steam game segments to identify opportunities for game developers with limited resources.

<img src="https://raw.githubusercontent.com/Anastasiia-A-Petrova/steam-market-opportunity-analysis/main/images/dashboard.png" width="700" alt="Steam Market Opportunity Analysis Dashboard">

**Highlights:**

* analyzed ~1,000 Steam games released between 2024 and 2026;
* collected data using Steam Store API, Steam Web API and SteamSpy;
* built a Python data collection and preprocessing pipeline;
* analyzed market demand, competition and price barriers;
* created a composite Opportunity Score;
* evaluated market size using estimated owners;
* performed sensitivity analysis of model weights;
* built an interactive Excel dashboard using Power Query and Excel formulas;
* identified Massively Multiplayer as the strongest overall market opportunity.

🔗 Repository: [steam-market-opportunity-analysis](https://github.com/Anastasiia-A-Petrova/steam-market-opportunity-analysis)
