## 🛒 GA4 Ecommerce Analytics

**BigQuery SQL | GA4 | Power BI**

Проект полного цикла по анализу данных интернет-магазина на основе событий Google Analytics 4 с использованием BigQuery SQL и Power BI.

<img src="https://raw.githubusercontent.com/Anastasiia-A-Petrova/ga4-ecommerce-analytics/main/images/customer_and_funnel_analysis.png" width="700" alt="GA4 Ecommerce Analytics Dashboard">

**Основные результаты:**

* анализ более **4,3 млн событий GA4**;
* исследование структуры данных и проверка их качества;
* расчёт ключевых ecommerce-метрик (Revenue, Transactions, AOV);
* сегментация клиентов и анализ повторных покупок;
* анализ эффективности товаров;
* анализ маркетинговых каналов и аудитории;
* интерактивный Power BI дашборд с четырьмя аналитическими страницами.

🔗 **Репрозиторий**: [ga4-ecommerce-analytics](https://github.com/Anastasiia-A-Petrova/ga4-ecommerce-analytics)
